# PHYSICAL CHEM LIVE

เกมแข่งขันวิทยาศาสตร์กายภาพ (เคมี) ม.5 โรงเรียนโพธิ์ศรีสว่างวิทยา สำหรับครูเปิดจอรวมและนักเรียนตอบพร้อมกันผ่านโทรศัพท์

## ฟังก์ชันสำคัญ

- คลังปรนัย 50 ข้อ: 40 ข้อจากข้อสอบเดิมและคำถามใหม่ 10 ข้อ
- สุ่มข้อสอบแบบกระจายหัวข้อ เลือกแข่งขัน 10–50 ข้อ
- Teacher Host สร้างรหัสห้อง 6 ตัวและ QR Code
- Waiting Room แสดงรายชื่อนักเรียนทันที
- นับถอยหลัง 15/20/30/45 วินาที ปิดรับอัตโนมัติ
- เฉลย คำอธิบาย คะแนน ความเร็ว Streak และอันดับสด
- เดินเกมอัตโนมัติ หรือครูกดพัก/ข้าม/จบเกมได้
- Practice Quest 20 ข้อ พร้อมคำใบ้และเฉลย
- หน้าสรุปผลสำหรับพิมพ์หรือบันทึก PDF
- Responsive: มือถือ แท็บเล็ต คอมพิวเตอร์ และจอโปรเจกเตอร์

## ทดลองทันที

เปิด `index.html` ผ่าน Live Server จะทำงานใน Demo Mode ข้อมูลส่งข้ามแท็บในเบราว์เซอร์เดียวกันได้ เหมาะสำหรับตรวจหน้าจอและลำดับเกม

## เปิดเล่นหลายเครื่องด้วย Firebase

1. สร้างโปรเจกต์ที่ Firebase Console
2. เพิ่ม Web App แล้วคัดลอกค่า `firebaseConfig`
3. เปิด Authentication > Sign-in method และเปิด Anonymous
4. สร้าง Realtime Database เลือกตำแหน่ง Singapore/Asia
5. แก้ `firebase-config.js`: วางค่าจริงใน `FIREBASE_CONFIG` และเปลี่ยน `DEMO_MODE` เป็น `false`
6. ที่ Realtime Database > Rules วางเนื้อหาจาก `database.rules.json` แล้ว Publish
7. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub repository และเปิด Settings > Pages > Deploy from branch (`main` / root)
8. ครูเปิด URL เดียวกัน เลือก “ครูเปิดห้อง”; นักเรียนสแกน QR หรือเปิด URL แล้วเลือก “นักเรียนเข้าร่วม”

> หมายเหตุด้านความปลอดภัย: กฎที่ให้มารองรับการใช้งานในชั้นเรียนแบบ Anonymous และเน้นติดตั้งง่าย ผู้ที่มีลิงก์และเข้าสู่ระบบแบบ Anonymous สามารถอ่าน/เขียนห้องได้ ควรลบห้องเก่าหลังใช้งาน และเพิ่ม Cloud Functions/Custom Claims หากนำไปใช้เป็นระบบสอบทางการระดับสูง

## การให้คะแนน

- ตอบถูก: 600 คะแนน
- โบนัสความเร็ว: สูงสุด 400 คะแนน
- ตอบถูกต่อเนื่องตั้งแต่ 3 ข้อ: โบนัส 100 คะแนนต่อข้อ
- ตอบผิดหรือหมดเวลา: 0 คะแนน

สร้างโดย คุณครูสุพักตร์ศิริ พืชสิงห์ โรงเรียนโพธิ์ศรีสว่างวิทยา
